## 2. Abstract

The **Interactive CFG and PDA Learning Tool** is an educational software platform developed to bridge the gap between abstract mathematical concepts and practical comprehension in the study of Context-Free Grammars (CFGs) and Pushdown Automata (PDAs). Designed specifically for computer engineering students, the system eliminates the obscurity typically associated with grammar transformations and automata simulations.

The software implements genuine algorithmic pipelines for:
1. CFG rule validation, diagnostic analysis, and leftmost/rightmost derivation stepping;
2. A rigorous 6-stage transformation to Chomsky Normal Form (CNF);
3. Greibach Normal Form (GNF) conversion including left-recursion elimination and variable substitution;
4. The dynamic programming Cocke-Younger-Kasami (CYK) membership testing algorithm with an interactive triangular DP matrix and cell inspector;
5. A formal 7-tuple Pushdown Automaton simulator supporting non-deterministic breadth-first search (BFS), step-by-step interactive stack stepping, and directed state-transition visualization.

Built using Python, Streamlit, and Graphviz, the application requires zero external API keys, paid services, or internet connections for core operations. Experimental validation demonstrates 100% test pass rate across 24 automated unit and boundary test cases.

## 7. Theory: CFG, PDA, CNF, GNF, and CYK

### 7.1 Context-Free Grammars (CFG)
A Context-Free Grammar is formally defined as a 4-tuple:
$$G = (V, \Sigma, R, S)$$
Where:
- $V$ is a finite set of non-terminal variables.
- $\Sigma$ is a finite set of terminal symbols disjoint from $V$ ($V \cap \Sigma = \emptyset$).
- $R \subseteq V \times (V \cup \Sigma)^*$ is a finite set of production rules. Each rule is written as $A \to \alpha$ where $A \in V$ and $\alpha \in (V \cup \Sigma)^*$.
- $S \in V$ is the distinguished start symbol.

The language generated by $G$ is:
$$L(G) = \{ w \in \Sigma^* \mid S \Rightarrow^* w \}$$

### 7.2 Chomsky Normal Form (CNF)
A context-free grammar is in Chomsky Normal Form if all production rules are of the form:
1. $A \to BC$, where $A, B, C \in V$ and neither $B$ nor $C$ is the start symbol if the language contains $\epsilon$.
2. $A \to a$, where $a \in \Sigma$.
3. $S_0 \to \epsilon$, permitted if and only if $\epsilon \in L(G)$, in which case $S_0$ must not appear on the right-hand side of any production.

### 7.3 Greibach Normal Form (GNF)
A CFG is in Greibach Normal Form if all productions are of the form:
$$A \to a \alpha$$
Where $a \in \Sigma$ is a single terminal symbol, and $\alpha \in V^*$ is a string of zero or more non-terminals (with the optional exception of $S_0 \to \epsilon$ if $\epsilon \in L(G)$).

### 7.4 Cocke-Younger-Kasami (CYK) Algorithm
The CYK algorithm is a dynamic programming algorithm that decides whether a string $w = w_1 w_2 \dots w_n$ of length $n$ belongs to $L(G)$ for a grammar $G$ in CNF.
It constructs a triangular table $T$, where $T[l][i]$ denotes the set of variables that can derive the substring $w[i \dots i+l-1]$ of length $l$ starting at index $i$:
- **Base Case ($l = 1$):**
  $$T[1][i] = \{ A \in V \mid A \to w_i \in R \}$$
- **Inductive Step ($l = 2 \dots n$):**
  $$T[l][i] = \bigcup_{k=1}^{l-1} \{ A \in V \mid A \to BC \in R, B \in T[k][i], C \in T[l-k][i+k] \}$$
- **Decision:** $w \in L(G) \iff S \in T[n][0]$.
- **Time Complexity:** $O(n^3 \cdot |R|)$, where $n = |w|$ and $|R|$ is the number of productions.

### 7.5 Pushdown Automata (PDA)
A Pushdown Automaton is a 7-tuple:
$$M = (Q, \Sigma, \Gamma, \delta, q_0, Z_0, F)$$
Where:
- $Q$ is a finite set of states.
- $\Sigma$ is the input alphabet.
- $\Gamma$ is the stack alphabet.
- $\delta: Q \times (\Sigma \cup \{\epsilon\}) \times \Gamma \to \mathcal{P}(Q \times \Gamma^*)$ is the transition function.
- $q_0 \in Q$ is the initial state.
- $Z_0 \in \Gamma$ is the initial stack start symbol.
- $F \subseteq Q$ is the set of accepting (final) states.

## 9. Algorithm Descriptions

### 9.1 6-Stage CNF Conversion Pipeline
1. **Start Symbol Isolation:** If $S$ appears on any RHS, introduce new variable $S_0$ with production $S_0 \to S$.
2. **Elimination of $\epsilon$-Productions:** Compute nullable variables $N = \{A \mid A \Rightarrow^* \epsilon\}$. For each rule $A \to \alpha$, generate all combinations omitting subsets of nullable variables. Add $S_0 \to \epsilon$ if original start symbol was nullable.
3. **Elimination of Unit Productions:** Find unit pairs $(A, B)$ such that $A \Rightarrow^* B$ using only rules of form $X \to Y$. Replace unit rules with all non-unit productions of $B$.
4. **Removal of Useless Symbols:**
   - Compute generating symbols (variables deriving terminal strings).
   - Compute reachable symbols (symbols reachable from $S_0$).
   - Prune any non-generating and unreachable symbols.
5. **Terminal Replacement in Long Productions:** For productions of length $\ge 2$ containing terminals $a$, replace $a$ with a fresh variable $T_a$ and add rule $T_a \to a$.
6. **Binarization:** For productions of length $k > 2$, cascade new variables $C_1, C_2, \dots$ so that all productions have exactly 2 variables on the RHS.

### 9.2 PDA Non-Deterministic BFS Simulator
To simulate non-deterministic PDAs with cycle prevention:
- Configurations are represented as `(state, remaining_input_tuple, stack_tuple)`.
- A queue manages configurations explored in a breadth-first search.
- A visited set stores explored configurations to break infinite loops caused by $\epsilon$-transitions that do not consume input or alter the stack.
- When an accepting configuration is reached ($q \in F$, input empty), the path is reconstructed into a step-by-step history table.

## 15. Limitations

1. **Deterministic Bounds:** To prevent infinite execution on recursive grammars with cycles, the derivation search employs bounded BFS (depth limit $\le 25$).
2. **Complex Left-Recursion in GNF:** GNF conversion supports all standard grammars with direct left recursion; highly intricate mutual indirect left recursions beyond configured iteration bounds return informative scope notices.
3. **Context-Free Scope:** The tool strictly models Context-Free Grammars and Pushdown Automata; Context-Sensitive Grammars (CSGs) and Turing Machines (TMs) are outside its theoretical scope.
